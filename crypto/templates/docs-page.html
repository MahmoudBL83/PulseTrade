Exchanges

PulseTrade supports a wide range of cryptocurrency exchanges through the ccxt Python library. You can seamlessly connect your exchange accounts to streamline trading and portfolio management.

3.1 API Key Setup

  1. Log in to the Exchange:
    • Visit the official website of the exchange you want to connect.
    • Log in to your exchange account.
  2. Generate API Keys:
    • Locate the API key creation section in your exchange account settings.
    • Generate a new set of API keys, ensuring you grant the necessary permissions for trading and account information retrieval.
  3. Add API Keys to PulseTrade:
    • Log in to your PulseTrade account.
    • Navigate to the "Connect Exchanges" section.
    • Click on the "Add Exchange" button.
    • Select the exchange you want to connect.
    • Enter the API key and secret key obtained from the exchange.
  4. Encrypting API Keys:
    • For enhanced security, PulseTrade uses the Fernet library to encrypt API keys.
    • Your API keys are securely stored and only decrypted when needed for trading operations.

3.2 Troubleshooting Connection Issues

If you encounter issues connecting your exchanges, consider the following troubleshooting steps:

  • Double-check API Keys: Ensure that you have entered the correct API key and secret key.
  • Permissions: Verify that the API keys have the necessary permissions for trading and data retrieval.
  • Firewall and IP Whitelisting: Some exchanges may require whitelisting IP addresses. Ensure your server's IP is whitelisted.
  • Exchange Status: Check the status page of the exchange for any ongoing maintenance or issues.

If issues persist, please refer to the "Troubleshooting" section in this documentation or contact our support team for assistance.

4.2 Configuring Bot Settings

When configuring your bot, consider the following settings:

  • Name: Provide a unique name for your trading bot.
  • Bot Type: Choose between "Single Pair" or "Multi Pair" trading.
    • single mean that the bot settings will apply to one pair; while multi mean that the bot will apply that settings on multi pairs
  • Pairs: Define the trading pairs for your bot.
  • Strategy: Specify the trading strategy, including "Long" or "Short" positions.
    • Base Order Size: Set the base order size for your strategy.
      • Base Order Size mean that the bot will open the first deal with that amount
    • Deal Start Condition: Based on indicators like RSI, MACD, etc.
      • Deal Start Condition mean that the bot will start the deal when the price reach the condition

      Relative Strength Index (RSI)

      • Length: The number of periods used for calculating the Relative Strength Index.
      • Timeframe: The timeframe or interval for which the RSI is calculated (e.g., 30 minutes, 1 hour, 1 day).
      • Condition: The type of condition to be checked, such as "Overbought," "Oversold," "Crossing Up," or "Crossing Down."
      • Signal Value: The specific value used for the condition check.

      Moving Average Convergence Divergence (MACD)

      • Fast Length:The number of periods used for calculating the fast exponential moving average in MACD.
      • Slow Length: The number of periods used for calculating the slow exponential moving average in MACD.
      • Signal Smoothing: The number of periods used for smoothing the MACD line.
      • Condition: The type of condition to be checked, such as "Crossing Up," "Crossing Down," "Positive Divergence," or "Negative Divergence."
      • Signal Value: The specific value used for the condition check.
      • Timeframe: The timeframe or interval for which MACD is calculated (e.g., 30 minutes, 1 hour, 1 day).

      Money Flow Index (MFI)

      • Length: The number of periods used for calculating the Money Flow Index.
      • Condition: The type of condition to be checked, such as "Overbought," "Oversold," "Crossing Up," or "Crossing Down."
      • Signal Value: The specific value used for the condition check.

      Parabolic SAR

      • Acceleration Factor: The acceleration factor used in the Parabolic SAR calculation.
      • Maximum Acceleration: The maximum acceleration factor that can be reached in the Parabolic SAR calculation.
      • Condition: The type of condition to be checked, such as "Bullish Reversal," "Bearish Reversal," "Crossing Up," or "Crossing Down."
      • Timeframe: The timeframe or interval for which Parabolic SAR is calculated (e.g., 30 minutes, 1 hour, 1 day).

      Commodity Channel Index (CCI)

      • Length: The number of periods used for calculating the Commodity Channel Index.
      • Timeframe: The timeframe or interval for which the CCI is calculated (e.g., 30 minutes, 1 hour, 1 day).
      • Condition: The type of condition to be checked, such as "Greater Than," "Less Than," "Crossing Up," or "Crossing Down."
      • Signal Value: The specific value used for the condition check.

      Bollinger Bands

      • BB% Period: The number of periods used for calculating the Bollinger Bands percentage.
      • Deviation: The standard deviation multiplier used in Bollinger Bands calculation.
      • Timeframe: The timeframe or interval for which the Bollinger Bands are calculated (e.g., 30 minutes, 1 hour, 1 day).
      • Condition: The type of condition to be checked, such as "Greater Than," "Less Than," "Crossing Up," or "Crossing Down."
      • Signal Value: The specific value used for the condition check.

      Ultimate Oscillator

      • Fast Length: The number of periods used for calculating the fast moving average in the Ultimate Oscillator.
      • Middle Length: The number of periods used for calculating the middle moving average in the Ultimate Oscillator.
      • Slow Length: The number of periods used for calculating the slow moving average in the Ultimate Oscillator.
      • Condition: The type of condition to be checked, such as "Greater Than," "Less Than," "Crossing Up," or "Crossing Down."
      • Signal Value: The specific value used for the condition check.
      • Timeframe: The timeframe or interval for which the Ultimate Oscillator is calculated (e.g., 30 minutes, 1 hour, 1 day).

      Stochastic

      • K Length: The number of periods used for calculating the %K line in the Stochastic Oscillator.
      • K Smoothing: The smoothing parameter for the %K line.
      • D Smoothing: The smoothing parameter for the %D line.
      • K Condition: The type of condition for the %K line, such as "Greater Than," "Less Than," "Crossing Up," or "Crossing Down."
      • K Signal Value: The specific value used for the condition check for the %K line.
      • Condition: The type of condition to be checked between %K and %D, such as "K Crossing Up D" or "K Crossing Down D."
      • Timeframe: The timeframe or interval for which the Stochastic is calculated (e.g., 30 minutes, 1 hour, 1 day).
  • Take Profit: Specify the Take Profit settings.
    • Take Profit (TP): Configure TP settings, including percentage or conditions.
      • TP mean that the bot will close the deal when the price reach the take profit percentage
    • Trailing TP: Enable or disable trailing TP.
      • Trailing TP mean that the bot will follow the price and close the deal when the price reach the take profit percentage
  • Stop Loss (SL): Define stop loss settings.
    • Stop Loss Percentage: Set the percentage for stop loss.
    • Stop Loss Action: Choose between "Close Deal" or "Close Deal & Stop Bot."
      • Close Deal mean that the bot will close the deal and wait for the next deal, while Close Deal & Stop Bot mean that the bot will close the deal and stop the bot
    • Stop Loss Timeout: Specify the timeout for stop loss actions.
      • Timeout mean that the bot will wait for the timeout to close the deal
    • Trailing Stop Loss: Enable or disable trailing stop loss.
      • Trailing Stop Loss mean that the bot will follow the price and close the deal when the price reach the stop loss percentage
    • Safety Orders: Configure safety order settings.
      • Safety Orders mean that the bot will open a new deal when the price go down
  • Advanced Settings: Access additional advanced settings for fine-tuning your bot's behavior.

Entry Trade Section

The Entry Trade section allows you to specify the details of your trade, divided into three key components: Entry Trade, Take Profit, and Stop Loss. Let's focus on the Entry Trade for now.

  • 1. Trade Entry Options

    • Use Existing Asset: Use your current assets for the trade.
    • Make Order: Create a new order for the trade.
    • Example: If you have 1 Bitcoin in your account and choose "Use Existing Asset," the system will use this existing Bitcoin for the trade. If you choose "Make Order," you can specify a new amount to trade, for example, 0.5 Bitcoin.

  • 2. Units

    • Units Input: Specify the amount of cryptocurrency you want to trade.
    • Example: If you input 10 units of Ethereum, it means you are initiating a trade for 10 units of Ethereum.

  • 3. Buy Price

    • Buy Type: Choose between "Limit," "Market," or "Conditional" orders.
    • Example: If you select "Limit Order" and set the "Buy Price Input" to $200, the system will execute the trade when the market price reaches $200.
    • Conditional Buy Type (Conditional Order Only): Choose between "Cond. Limit Order" and "Cond. Market Order."
    • Example: If you choose "Cond. Limit Order" and set the "Trigger Price" to $180, the system will trigger the order when the market price reaches $180.

  • 4. Total

    • Total Input: Displays the total value of your trade.
    • Example: If the total input shows $2,000, it means you are initiating a trade worth $2,000 based on the specified units and buy price.

    • Take Profit Section

    The Take Profit section allows you to set conditions for selling your assets to realize profits after entering a trade. This section consists of various options to customize your take profit strategy.

    • 1. Take Profit Switch

      • Enable/Disable Take Profit: Use the switch to enable or disable the take profit functionality.

    • 2. Order Type

      • Select Order Type: Choose between "Limit Order" and "Market Order" for executing the take profit.

    • 3. Take Profit Targets

      • Profit Percentage: Set the percentage of profit you want to achieve from the entry size.
      • Volume Percentage: Specify the percentage of the total entry size to sell.
      • Add TP Targets: Click this button to add take profit targets.

    • 4. Trailing Take Profit

      • Enable/Disable Trailing TP: Use the switch to enable or disable trailing take profit.
      • Example: If you enable "Trailing TP" and set the percentage to 3%, the system will dynamically adjust the take profit level as the market price increases. If the market price increases by 3%, the take profit level will be updated accordingly.

    Stop Loss Section

    The Stop Loss section allows you to set conditions for selling your assets to minimize losses after entering a trade. This section consists of various options to customize your stop loss strategy.

    • 1. Stop Loss Switch

      • Enable/Disable Stop Loss: Use the switch to enable or disable the stop loss functionality.

    • 2. Order Type

      • Select Order Type: Choose between "Limit Order" and "Market Order" for executing the stop loss.
      • Example: When setting up your stop loss, you have the option to choose between "Cond. Limit Order" and "Cond. Market Order."
        • Cond. Limit Order: If you choose this option, you are specifying a particular price at which the stop loss order will be triggered. For instance, setting a "Cond. Limit Order" with a trigger price of $150 and an order price of $145 means that the stop loss order will only be placed when the market price reaches $150 or better, and the order will be executed at a limit price of $145 or better.
        • Cond. Market Order: Alternatively, opting for a "Cond. Market Order" means that the stop loss order will be triggered and executed at the best available market price when the specified condition is met. This is useful when you want the order to be executed promptly without specifying a particular limit price.

    • 3. Trailing Stop Loss

      • Enable/Disable Trailing SL: Use the switch to enable or disable trailing stop loss.
      • Trailing SL Percentage: Specify the percentage of loss you want to minimize from the entry size.
      • Example:Trailing Stop Loss is a dynamic strategy that automatically adjusts the stop loss level as the market price moves in your favor.
        • If you enable "Trailing SL" and set the percentage to 3%, it means that the stop loss will trail behind the market price, maintaining a distance of 3% below the highest market price since you entered the trade.
        • For instance, if you enter a trade at $100 and the market price increases to $110, the initial stop loss would be at $97 (3% below the highest price of $110). If the market continues to rise to $120, the stop loss would automatically adjust to $116.4 (3% below $120).
        • This feature helps lock in profits while allowing room for the trade to unfold favorably, automatically adjusting to changing market conditions.

    • 4. Stop Loss Timeout

      • Enable/Disable Timeout: Use the switch to enable or disable the timeout functionality.
      • Timeout: Specify the timeout for stop loss actions.
      • Example: If you enable "Timeout" and set it to 30 minutes, the system will wait for 30 minutes before executing the stop loss action, giving the market some time to potentially recover.

    • 5. Move to Breakeven

      • Enable/Disable Move to Breakeven: Use the switch to enable or disable the move to breakeven functionality.
      • Example: If you enable "Move to Breakeven" and set the take profit percentage to 5%, the system will move the stop loss to the entry price when the market price increases by 5%, securing your initial investment.
